# 🚀 Mukesh Veeravalli — 3D Developer Portfolio

> **Created by [Mukesh Veeravalli](https://github.com/Mukesh1701)**

Interactive & responsive **3D developer portfolio** built with **React**, **TypeScript**, **Three.js**, **GSAP**, and **WebGL** — featuring an AI chat assistant and a playable chess bot.

## ✨ Features

- 3D / WebGL experience powered by Three.js (animated 3D character that follows your mouse)
- Smooth animations with GSAP + Lenis smooth scrolling
- AI chat assistant that answers questions about me
- Play chess against an in-browser AI engine at `/play`
- Modern React + TypeScript codebase, fully responsive

## 🧰 Tech Stack

Python · JavaScript · C++ · Java · Dart · React · HTML/CSS · Tailwind · Flutter · FastAPI · Spring Boot · Node.js · MySQL · MongoDB · PyTorch · OpenCV · NumPy · Pandas · OpenAI · Git · VS Code · Postman · Figma

## 📦 Projects Featured

- **NutriScan AI** — AI-powered food scanner (React, FastAPI, PyTorch)
- **EduTracker** — Student activity points platform (Flutter, Spring Boot, MySQL)
- **Jarvis** — Python voice assistant (OpenAI, wake-word detection)
- **NeetCode Submissions** — DSA practice in C++
- **Play Chess vs AI** — browser chess with an AI engine

## 🚀 Getting Started

```bash
npm install
npm run dev      # local dev server
npm run build    # production build
```
